
# توسيع "مخطط الهندسة الفيروسية" من 8 لوحات إلى 13

سأنفّذ وثيقة التطوير كاملة (P1 → P7) دفعة واحدة، مع الالتزام بقاعدتها الأساسية: **لا تعديل على اللوحات 01-07** سوى تصحيح الرقم الإجمالي.

## الوضع الحالي (تم التحقق منه)
- `src/routes/index.tsx` (1208 سطر) يحتوي مصفوفة `SHEETS` بـ 8 عناصر، والفهرس الجانبي + قائمة الموبايل يُولَّدان تلقائياً منها.
- كل اللوحات تعرض `SHEET 0X / 08`، واللوحة الختامية `id="s08"` فيها `check-grid` وزر "ابدأ التنفيذ الآن"، والتذييل `REV B`.
- الأصناف المطلوبة موجودة كلها في `styles.css`: `.panel` `.paper` `.grid-2/3/4` `table.tech` `.table-wrap` `.tl` `.quote` `.badge` `.check-item` وآلية `.reveal` عبر IntersectionObserver تلتقط تلقائياً أي عنصر جديد.
